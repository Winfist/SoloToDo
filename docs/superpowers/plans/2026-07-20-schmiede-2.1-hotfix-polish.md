# Schmiede 2.1 Hotfix + Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die fünf iPhone-Befunde der Schmiede fixen — Loadout-Sichtbarkeit angenommener Quests, Safe-Areas/Scroll-Lock, ehrliche Auswahl-Kappung, lebendige Ladephase, spürbares Accept-Feedback — plus Prompt-Nachschärfung.

**Architecture:** Ein Forge-Rang im bestehenden Loadout-Comparator garantiert Board-Sichtbarkeit; `getSelectableCount` kappt zusätzlich auf `QUEST_LOADOUT_CAP`; das Ritual-Overlay bekommt Safe-Area-Paddings, Body-Scroll-Lock, rotierende Status-Zeilen mit Elapsed-Anzeige und eine kurze Erfolgs-Phase vor dem Schließen.

**Tech Stack:** Vite + React 18 (JSX, Inline-Styles), reine ES-Module in `data/`, Node-Testskripte in `scripts/`.

**Spec:** `docs/superpowers/specs/2026-07-20-schmiede-2.1-hotfix-polish-design.md` (8593daf).

## Global Constraints

- de.js ECHTE Umlaute; `functions/` ASCII-Deutsch (ue/ae/oe); jede neue UI-Zeile in de UND en.
- Design: NEXUS dunkel + Indigo, KEIN Neon/Glow; Puls-Animation nur Opacity/Scale.
- Ehrlichkeit: Ladephase endet nur über Props (echter Call), Statuszeilen loopen (kein Fake-Fortschrittsbalken, keine Fake-Prozente).
- Sichtbarkeits-Semantik exakt: Forge-Rang NACH Fokus/Systemzeichen/Pin/Überfällig, VOR Chain/eigene/übrige.
- Auswahl-Kappung exakt: `getSelectableCount = min(QUEST_LOADOUT_CAP, getDailySystemQuestCount, countManualForgeTargets)`; Anzeige zusätzlich `min(…, proposals.length)`.
- Safe-Areas exakt: Kopf `max(env(safe-area-inset-top, 0px), 14px)`, Fuß `calc(max(env(safe-area-inset-bottom, 0px), 12px) + 12px)`, X-Button 44×44.
- Tests: Muster `scripts/test-*.mjs` (check-Helper, exit 1, Abschlusszeile `alles gruen`).
- Commits deutsch (`fix(forge): …`), je Task-Ende.

    return Math.max(0, Math.min(

      getDailySystemQuestCount(state || {}),
      countManualForgeTargets(state?.quests || [])
    ));
  } catch {
    return 0;
  }
}
