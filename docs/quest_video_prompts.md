# Quest Video Prompts — SoloToDo

> **Target**: Google Veo / OMNI  
> **Format**: 8-second seamless loop, 1080p, 24fps  
> **Style**: Dark anime (Solo Leveling aesthetic)

---

## Master Template

Paste this **before** every exercise prompt. It defines the universal visual language.

```
8-second seamless loop. Dark anime cel-shaded art style. Single male figure, 
lean athletic build, short dark hair, seen from a low three-quarter angle. 
Setting: dimly lit concrete training room, a single overhead industrial light 
casting harsh downward shadows. Muted tones — charcoal, slate, steel blue — 
with one accent color: electric cyan from a faint aura outlining the figure's 
body on each exertion. No text overlays, no HUD, no UI elements. No background 
characters. Subtle dust particles floating in the light cone. Camera is 
locked — no pans, no zooms, no cuts. The animation loops perfectly from 
last frame back to first frame.
```

## Prompt Usage Notes

1. **Always paste the Master Template first**, then the specific exercise prompt
2. **Set generation to 8 seconds** and request seamless loop
3. **Do NOT add text/HUD overlays** — the template explicitly forbids them
4. **One action per video** — even multi-exercise quests get a single representative movement
5. **The cyan aura is the only "magical" element** — everything else is grounded and physical
6. **Camera never moves** — this prevents jarring loop resets and keeps the focus on form
7. **Dust particles and sweat** are the ambient details — not sparkles, not runes, not floating text
